# Security Policy

## Supported version

Limmud is in early development. Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** form in the repository's Security tab. Include:

- A clear description of the issue and its impact
- Reproduction steps or a minimal proof of concept
- Affected operating systems or versions
- Any suggested mitigation

Do not include sensitive exploit details in a public issue. You can expect an initial acknowledgment within seven days, but response and remediation times depend on severity and maintainer availability.

## Scope

Reports involving filesystem boundaries, local media serving, terminal sessions, dictionary-pack validation, or unintended disclosure of course data are especially useful.
