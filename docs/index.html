WHY IT EXISTS

Less friction. More focus.

Designed around simple, offline-first workflows. These are the features in the project's published scope.

01

Everything in one workspace

Play a downloaded course while keeping notes, progress, and tools beside it.

02

Continue learning offline

Resume video playback, keep bookmarks, mark lessons complete, and track focus time.

03

Your files stay yours

Course videos, notes and learning state remain on your machine without a required account.

04

Terminal when you need it

Use an embedded multi-pane terminal during technical lessons without leaving the workspace.

05

Keep learning context

Markdown notes, todos, subtitles and an optional offline dictionary stay close to your lessons.

06

Desktop and Android dev builds

Tauri/Rust + React desktop architecture, with an Android development workflow in progress.

THE WORKFLOW

Three steps, one clear experience.

Choose a folder

Point Limmud to your locally stored course lessons.

Learn in one place

Watch, write Markdown notes, use the terminal, and track progress.

Come back without losing context

Limmud saves lesson state beside your local course files.

UNDER THE HOOD

Your courses stay on your computer.

Limmud uses Tauri 2 and Rust for local filesystem access, with a React/TypeScript workspace for video, notes and tools. It has no required hosted backend, user account, or analytics collection.

Development builds, not an app store release. Limmud v0.1.0 is early-stage. Its core desktop and Android development workflows are documented and testable, but signed installers are not yet published. Check the repository for setup steps and development status.
