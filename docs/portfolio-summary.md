# Portfolio Summary

**Title:** Offline Desktop Study Workspace

**Role:** Full-Stack Desktop App Developer

**Description:** Built a local-first desktop study application for organizing downloaded course material in one focused workspace. The app scans local lesson folders, plays videos with resume progress and subtitles, saves Markdown notes and todos, tracks completion and study time, and provides an embedded terminal and optional offline dictionary. Course data remains on the user's machine.

**Skill tags:**

- Tauri
- Rust
- React
- TypeScript
- SQLite

## Important features

- Local course-folder scanning and lesson organization
- Offline video playback, subtitles, and resume progress
- Local notes, todos, bookmarks, vocabulary, and study tracking
- Embedded terminal and resizable desktop workspace
- No required account, hosted backend, analytics, or telemetry
